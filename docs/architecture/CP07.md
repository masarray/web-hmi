# CP-07 — Read-only server-owned realtime tag engine

## Reference and copyright boundary

Studied FUXA pinned commit a7705f084c1439edf1b27c1f69c737b8d6de0e00:
- server/runtime/index.js: central device events and client tag subscriptions
- server/runtime/devices/: industrial driver adapters
- server/main.js and server/fuxa.js: socket.io and runtime composition

We preserve the proven **one acquisition layer for many viewers** workflow, but
implement a new, small and typed server. No FUXA source is copied here.
The existing attributed FUXA SVG artwork stays unchanged.

## Architecture

- server/tag-hub.ts: one bounded tag cache/source, tag-to-client fanout,
  WebSocket upgrade origin gate, payload/subscription caps and buffered-byte
  client eviction. No arbitrary commands, server expression evaluation or
  direct client-to-device writes.
- src/shared/tag-protocol.ts: versioned, exact tag identifiers and messages.
- src/app/editor/tag-stream-client.ts: single WebSocket connection per HMI
  browser, reconnection with exponential backoff, handshake, heartbeat
  watchdog, server snapshot, and fail-closed local quality on disconnection.
- Angular Studio Preview: manual source selection between Local Simulator
  (CP-06) and Node.js Tag Server (DEMO). Preview UI prominently identifies
  simulated/read-only data. Existing project JSON and edit/undo are unchanged.
- A server heartbeat is **not** a tag update. Each sample uses browser-local
  arrival time, retaining the CP-06B automatic 3-second tag STALE policy.
- Per-client replace-subscription is exact, deduplicated and limited to 128
  names; the server source ticks only once independent of client count.
- Security: bind loopback only, explicit Origin allowlist, 64-client limit,
  32-KiB inbound message limit, 128-KiB queued-outbound limit, no compression,
  transport ping/pong, read-only /health. No CORS-open HTTP mutation routes.

## Local development

Terminal 1: npm run start:server (127.0.0.1:8787).
Terminal 2: npm start (Angular on 127.0.0.1:4200).
In Web HMI Studio add a Motor symbol, set tag Plant/Motor, choose Rotate, click
Preview, then choose **Node.js tag server**. Plant/Gear and Pump/Pressure are
also available in the server-owned demo feed. Unknown tags remain STALE.
No industrial drivers, authorization for writes or field equipment endpoints
exist in CP-07.

## Acceptance

- npm test — model, visual, protocol, fanout and source integration
- npm run typecheck and npm run typecheck:server
- npm run build — Angular AOT production
- npm run test:e2e — all existing browser scenarios plus server-backed HMI
- No user artifact needed. CI and PR must remain green before milestone closure.

## Deferred production requirements

Server authentication/multi-user roles, TLS+reverse-proxy, secure host
configuration, industrial adapter workers, production on-disk project store,
simulator disabled in production, audit logging, resource quotas and actual
hardware commissioning. CP-07 is **runtime architecture**, not a validated
industrial gateway or live SCADA control system.
